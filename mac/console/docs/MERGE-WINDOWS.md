# Windows 合并边界

请提供 Windows「本地模型控制台」实际源码、依赖清单、版本与启动方式；不要提供上游 OAuth 数据库、API key 或含密钥的真实 frp 配置。

沿用现有 Pinokio / Ollama 项目，先确认它是否监督 frpc，避免新增第二个守护器。截图无法代替这一步。

| 组件 | 合并方法 |
| --- | --- |
| Windows Ollama | 在原控制台加入独立启动/停止，不把 Pinokio42000 当推理接口；本地模型仍用11434 |
| Windows frp | 每节点独立配置，按配置与进程身份管理；不得全局taskkill |
| Mac Ollama | 继续11435统一入口与现有管理器；复用本预览adapter |
| Sub2API | VPS HTTPS与原STCP各有配置和下游密钥，不自动交叉发送 |
| 网页聊天 | 可复用本预览的页面与固定Ollama代理；不公开监听、不自动转云端 |
| Tailscale | 独立辅助入口，不随frp开关操作全机VPN |
| 更新 | 先确定同一GitHub仓库与版本协议，再加入校验、暂存、原子替换、保留私人配置和回滚 |

本次只验证 Mac；Windows worker、原生GUI与安装生命周期未实测。不要直接替换正在运行的Windows项目。先合并一个隔离副本，再逐项验收：独立开关、重复启动、停止释放端口、真实API/流式、节点失败、回滚和私人文件排除。
