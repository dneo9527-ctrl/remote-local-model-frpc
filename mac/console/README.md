# Mac 模型接收端

核心界面：Windows 模型连接、VPS 线路、连接开关、Cherry Studio、流式网页聊天。已配置 Sub2API 时另有独立连接开关、连接选择、手动健康检查和 CC Switch 入口。更新与日志收在管理入口。

首页与菜单栏状态刷新使用被动接口，不请求远端。点击“检查 API”或“诊断”先打开分层诊断窗口，窗口内健康、认证检查与最小 Responses 请求分别手动触发。结果绑定当时连接并显示时间，超过五分钟、连接变化或隧道子进程重建后标为过期。健康通过也不代表认证、Responses 或 Codex 对话已验收。18081 被外部 visitor 占用时不接管、不停止。控制台仅管理连接，旧 Codex 配置写入动作已禁用，供应商与认证交给 CC Switch。示例设置 `automatic_health_checks=false`；兼容的非被动旧状态接口保留原配置语义。

从统一项目根目录运行 `python3 tools/launch.py --config /absolute/private/settings.json --state /absolute/private/updates`。Python 3.11+，仅标准库；复用已有网关和 frpc，不下载模型。

Mac 原生菜单栏入口源码在 `mac/menu/LocalAIConsole.swift`，构建器为 `tools/build_mac_app.py`，需要本机已有 Swift/AppKit。菜单用电脑小图标显示控制台后台状态，支持打开页面、后台停止后重新启动和 **全部退出**；关闭网页不等于退出。全部退出会暂停本控制台配置的 Ollama 网关/visitor（含既有管理器的登录恢复），停止 Sub2API 连接，确认端口关闭后再退出后台与菜单。失败时保留界面供重试；下次打开后需按需开启连接。菜单只检查本机 session 身份，不探测上游；Windows 服务与私人配置保留。菜单进程意外退出时，其直接管理的后台检测父进程消失后尝试清理全部本机连接；异常清理未完成会记录失败。构建器仅输出新 `.app` 目录，不覆盖安装或添加登录项。准确本机回退材料由工具台账记录。

复制 `config.example.json` 到源码外，填写原模型管理器、解释器和私有 visitor 的绝对路径。线路列表 `ollama_routes` 每项引用自己的本机 STCP 配置；网页只收到名称与 ID，不收到密钥。切换先备份、只暂停本项目管理器；失败尝试恢复原配置。暂停状态下换线路仍保持暂停。

Windows 必须注册相同 VPS/provider/secret；本机保存了线路不等于远端已注册。线路区区分当前和待应用；本控制台的网页生成期间拒绝切换 Ollama 线路或停止该连接，外部客户端是否正在生成仍需用户确认。

“管理节点”支持表单新增、同 ID 编辑、复制节点、删除未使用节点，以及独立粘贴窗口导入配套 visitor TOML。地址支持 `IP:端口`、`[IPv6]:端口`，高级参数仍可编辑；地区自动识别。两张卡的节点选择入口共用一个池，显式应用时同时切两路，保留各自开关。保存与导入不切线；使用中的节点修改保存后标为待应用。Ollama 和 Sub2API 各有自己的 provider 配置；两卡都是连接 Windows，VPS 只负责中转。已有凭据不回填到网页，空值保留；删除保留原私有文件和备份。配置只保存在本机工具私有目录，TLS 和 STCP 加密固定开启。完整 visitor 可复制到本机剪贴板，含隧道凭据但不含下游 API Key，仅私下传递。导入错误保留草稿，成功或关闭窗口清空输入。

网页聊天提供实际模型列表、流式文字与最近12条消息；本机默认模型仅保存在 `runtime/data/chat-preferences.json`，不改 Windows、Cherry 或 CC Switch。列表刷新保留当前有效选择，离线不会冒充空列表。原生同一窗口保留控制台和聊天两个视图，生成中返回控制台也保留流与草稿；全部退出或后端实例改变会清除内存会话。没有附件、持久聊天、自动压缩或MCP。

“分类日志”在面板内只展示识别出的固定事件摘要，不回显原始日志、节点、Key、请求正文或响应正文。Sub2API frps/provider 判断只采用当前连接开始之后的日志；未知状态明确标为未知。最小 Responses 检查使用认证模型列表中的精确名称，不自动猜测模型，也不自动重试。

详细步骤见根目录 docs。运行测试：`python3 -m unittest discover -s tests -v`。统一打包使用根目录 `tools/package_source.py`；不要打包安装目录、私人配置或交付 ZIP。
