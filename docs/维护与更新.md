# 双端维护与更新

同库协作：Windows 来源分支 `windows`，Mac/整合分支 `codex/mac-receiver`，最终由 PR 进入 `main`。不要互相覆盖历史或把私人配置提交上来。用户明确授权发布时，准确 commit 的 CI 通过后可建立预览 tag 与源码附件；源码分支推送和 GitHub Release 分别记录。

两端统一下载源为本仓库 Releases。稳定与预览显式选择；没有 Release 时显示“尚无已发布版本”，不能把分支最新提交叫做最新版。当前仅用户点击检查/执行命令时访问 GitHub，不添加定时调用或后台监控。

```sh
python3 tools/update.py check --channel preview
python3 tools/update.py baseline --source /absolute/audited/source --state /absolute/private/updates
python3 tools/update.py stage --channel preview --state /absolute/private/updates
python3 tools/update.py select --version 0.2.0-preview.1 --state /absolute/private/updates
python3 tools/launch.py --config /absolute/private/settings.json --state /absolute/private/updates
python3 tools/update.py rollback --state /absolute/private/updates
```

`baseline` 保存指定已审查源码，不是数据库备份。下载仅接受同仓库官方 Release 的精确名称源码 ZIP 和 SHA256SUMS；校验不等于作者身份签名。解压检查路径、链接、冲突、大小与私人文件，写入 `updates/releases/<version>`；选择和回滚只改变原子指针。启动器复核该目录完整性并读取指针，旧进程需先退出控制台后重新启动；不会热替换正在运行的服务。

首次升级必须先有可校验基线，保存白名单中的完整双端源码与界面资源。旧 `.app` 的原安装另行保留备份，不能把新源码基线冒称旧安装备份。

Windows 原 WPF 面板已合入。将 `mac/console/config.windows.example.json` 复制到源码之外，填写已有模型项目的绝对 `windows.project_root` 和独立 `runtime`，再从 PowerShell 运行：

```powershell
.\tools\Launch-Windows.ps1 -Config 'C:\Private\console-settings.json' -State 'C:\Private\console-updates'
```

启动器验证所选源码，用系统 .NET Framework 编译器在 `runtime/data/windows-builds/<源码摘要>/` 构建原生 EXE，保持 Release 源码不变；不覆盖原 EXE、项目配置、模型、frpc 或容器。再次打开复用经过摘要核验的编译缓存。关闭旧面板后再启动才使用新代码；打开窗口不会自动启动模型或隧道。Windows 原生 EXE 本身无需 Python，共享源码更新/启动器需要已有 Python 3.11+。旧版本缺少 WPF 适配时明确拒绝启动，不代开 Mac 网页。

Mac 和 Windows 的“检查更新”通往同一仓库；Mac 显示发布查询结果，Windows 打开 Releases。下载、校验、版本选择与回退仍是独立步骤，**不是一键升级运行中的服务**。`rollback` 后关闭新面板，再从统一入口启动；旧源码、编译缓存和私人项目都保留。更新 Sub2API 容器仍按其独立部署说明进行，本源码更新器不代为操作。

源码包名称：`remote-local-model-frpc-<version>-source.zip`，校验文件：`remote-local-model-frpc-<version>-SHA256SUMS.txt`；ZIP根为`remote-local-model-frpc/`。

Mac运行程序放LocalTools，私人设置在config、运行状态在data、日志在logs，更新源目录独立保存。不要把整个安装目录/git工作区作为更新包。卸载先退出控制台，保留私人数据与备份，移除该项目入口；原模型网关与厂商聊天数据分别处理，不全局杀进程或删除Docker卷。
