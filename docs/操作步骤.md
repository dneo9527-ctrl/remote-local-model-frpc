# 操作步骤

1. Windows 打开原“本地模型控制台”，启动模型和隧道，选 VPS。
2. Mac 打开桌面“本地 AI 控制台”，选择同名 VPS，打开连接开关。
3. 看到“Windows 模型已连通”后，打开 Cherry Studio 或网页聊天。
4. 在聊天软件的模型选择器换模型；常用 `qwen3-8b-8k:latest`。线路无需随模型改变。
5. 换 VPS 前结束当前回答；Windows、Mac 两边都切到同一个节点。
6. 暂时不用，关闭 Mac 连接开关；Windows 模型仍由 Windows 控制。
7. Mac 的更新与日志在“管理”中；Windows 在“操作记录与日志”中。更新前关闭旧面板，按版本说明操作；失败保留原版，不删除私人配置重装。

Mac API：`http://127.0.0.1:11435`；OpenAI 兼容：`http://127.0.0.1:11435/v1`。手机不能直接使用 Mac 的 `127.0.0.1`。
